共享 YScale 的双位置交互测试

测试目标：验证左右两个视觉 YAxis 引用同一个 default YScale

预期效果：拖拽任意视觉轴只修改一次 default YScale；左边显示价格，右边把同一批刻度投影为百分比

测试说明：
  • 拖拽左轴或右轴，观察两个位置是否同时反映同一个 scale 状态
  • 双击Y轴进入手动模式，再次双击恢复自动模式
  • 左右两个视觉轴引用同一个 default scale，范围和刻度坐标相同，但标签投影可以不同
尺度与显示说明：
  • Normal / Log 是 scale 的坐标变换，左右轴共享
  • Value / Percentage 是 visual axis 的标签投影，可以左右不同
  • 对数 scale 适合跨越多个数量级的正数数据；百分比标签仍基于转换后的真实价格

测试控制

⚠️ 对数轴要求数据为正数；左右视觉轴会一起切换
